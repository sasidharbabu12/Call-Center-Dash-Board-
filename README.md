Title / Headline
Call Center Dash Board : A Call center Total Function Dashboard
A dynamic, Interactive data visualization tool to explore call center data focusing on employee call handle time , CSAT Score , entire call center performance .

Description 
Designed an end-to-end Call Center Analytics Dashboard using Excel for ETL data transformation and Power BI for interactive reporting. 
Built DAX calculated columns and metrics to track key business KPIs, giving leadership actionable insights into call volumes, 
service-level compliance, and agent performance.

Tech Stack
The Dashboard was built using following Tools and Technologies:
Power BI Desktop - Main Data visualization platform used for report creation.
power Query - Data transformation and cleaning layers for reshaping and preparing the data.
DAX (Data Analysis Expression) - Used for calculated measures , dynamic visuals, conditional logic.
Data Modeling - Relationships established among tables (snow fleix schema ) to enable cross-filtration and aggregation.
File Format - .pdix for development and .png for dashboard preview 

Data Source 
Data is extracted from different call centers, all the data is  CSV/Text file & excel format  only. 

Features 
Business problem 
Call centers act as a vital bridge between customers and products or services. However, customer dissatisfaction remains a challenge. 
This project aims to identify the root causes of customer dissatisfaction and pinpoint key areas for operational improvement.

Business Impact 
By this dashboard we can identify employee performance in the call center their AVG (Call handling time) and CSAT Scores.
identifying the low CSAT scores individually & based on team lead and manger and zone and product, and why there are getting  low CSAT
Identifying key KPIS and letting company know where we need to work on and try to increase productivity .
